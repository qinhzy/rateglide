# RateGlide · 汇见

**Currency at your cursor — 让换算随手发生。**

[English](README.md) · 简体中文

在网页上选中 `$129.00`、`€ 1.234,56`、`HK$ 2,680` 或 `2.5万日元`，即可弹出换算。RateGlide 提供中英双语、汇款比价、Visa／万事达官方报价、Revolut 公开换币报价与关注币种，查询都在插件内完成。

## 安装

从 [GitHub Releases](https://github.com/qinhzy/rateglide/releases) 下载对应安装包，或按下文从源码构建。

- **Chrome / Edge**：解压 `rateglide-chrome-edge-<版本>.zip`；打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，点击“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。固定工具栏图标并刷新原有网页。源码构建对应 `release/chromium`。
- **Safari**：下载的是 Web Extension 资源包，并非签名完成的 macOS 应用。新版 Safari 可先启用网页开发者功能，再从“开发者 → 添加临时扩展”选择解压目录，按提示完成系统授权。临时扩展会在退出 Safari 或 24 小时后移除。长期安装需要完整 Xcode、宿主应用与 Apple 签名；构建后可运行 `zsh scripts/package-safari.sh` 生成项目，仍需自行配置签名。[Apple 说明](https://developer.apple.com/documentation/safariservices/running-your-safari-web-extension)

开发者安装不会自动更新。更新后需在扩展管理页重新加载，并刷新已有网页。请保留已加载的文件夹。

## 使用

1. 从工具栏右上角或“设置 → 偏好设置 → 界面语言”选择跟随浏览器、简体中文或 English。打开的插件页面会同步切换，网页划词浮层也遵循此设置。
2. 设置目标货币：新装中文环境默认 CNY，英文环境默认 USD；升级保留原有设置。
3. 在普通网页选中完整金额，点击“换算为…”；可修改歧义币种、复制结果或进入比价。`$` 默认美元，`¥` 默认日元。
4. “刷卡”同时查询 Visa 与 Mastercard 官方公布价，支持实际报价日期、最近一年内的历史查询、发卡行附加费和预计账单；费用只计入一次。
5. “比价”展示可用的银行／平台报价，支持币种、金额与地区筛选。Revolut 公开换币报价及套餐费用单独展示。机构目录可以在插件内查询汇丰、PayPal 等。
6. “设置 → 使用指南 → 打开划词练习页”无需本地服务器。可使用右键菜单或 `Alt / Option + Shift + C` 快捷键。

支持常见符号、ISO 币种代码、中文币名、欧美小数格式、印度数字分组、阿拉伯数字、万／亿和 k／m。纯数字识别默认关闭；输入框、密码框、可编辑区域、普通文本、日期、价格范围和多个价格默认不触发。浏览器设置页、扩展商店和内置 PDF 阅读器等受浏览器限制，可改用工具栏换算。

## 数据范围

| 来源              | 含义                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------- |
| Wise              | 实时中间价，缓存 60 秒，不含汇款手续费。                                                |
| ExchangeRate-API  | 最近实测覆盖 166 种货币的每日参考，每小时检查；不是盘中实时价。                         |
| Frankfurter       | 央行及官方机构每日参考，不是银行客户专属报价。                                          |
| 中国银行          | 官方人民币与外币的现汇买入／卖出价，按每 100 单位归一化，不虚构交叉牌价。               |
| Wise 比价         | 按路线、金额与地区返回采集估算，可包含汇丰、PayPal 等；不等于登录个人账户取得的成交价。 |
| Revolut           | 官方公开换币计算器，支持账户地区和套餐费用，并正确处理币种最小单位。                    |
| Visa / Mastercard | 官方计算器报价、实际公布日期、银行费率和预计账单。历史可查范围受官方可用数据限制。      |

全球货币覆盖不代表每家银行、每个客户的专属交易价格都公开可查。费用、支付方式、地区、会员权益、卡片处理日和发卡行政策可能影响最终金额。界面会分别标明实时中间价、每日参考、采集估算和卡组织公布价。

自动模式优先 Wise，失败时明确标注每日参考降级；指定来源不自动换机构。卡组织缓存区分币种、金额、日期与费率。旧缓存明确标注，不会用市场价冒充 Visa／万事达报价。公开接口可能限流或变更。

## 隐私

没有账户登录、广告、分析埋点或汇款功能，不读取银行凭据和卡号。选中文字在本机解析，只向固定报价来源发送必要查询字段，不上传网页全文、标题、浏览历史或选中原文。

设置与缓存保存在浏览器本地。历史默认关闭，开启后仅保存主动复制的最近 50 条换算，可清空、导出中英文 CSV。详见 [隐私说明](docs/PRIVACY.md)。

## 开发与测试

使用 Node.js 22+ 和 `package.json` 指定的 pnpm 版本。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm exec playwright install chromium webkit
pnpm test:i18n
pnpm package
```

打包命令需要 macOS / Linux 常见的 `zip`、`unzip`。预览运行 `pnpm dev`，地址为 `http://127.0.0.1:4173`。保持服务运行后，可执行 `pnpm test:browser`、`pnpm test:webkit` 和 `pnpm test:payments` 进行联网回归。

单元测试和双语扩展测试使用确定的数据与隔离浏览器配置；双语测试中的报价是明确的测试夹具，不是联网验收结果。真实联网支付测试使用正常可见 Chromium，不导入用户浏览器配置或 Cookie。GitHub Actions 自动执行单元测试、构建、双语扩展检查和打包。

当前提供 Chrome / Edge 的 Chromium 包和 Safari 资源包。Edge 尚未实机验收，Safari 长期签名发行及三个浏览器商店上架未完成。1.1 版本曾完成原生 Chrome 及 Safari 临时扩展验收；自动化 WebKit 检查不能替代原生 Safari 测试。测试通过不等于零 bug 或所有机构永久可用。

保留旧版 `huijian:` 本地存储键和内容脚本宿主 ID，便于兼容已有设置。`design/extension-public-key.txt` 是稳定 Chromium 扩展 ID 所需的公开 key，不是秘密，不包含私钥。
